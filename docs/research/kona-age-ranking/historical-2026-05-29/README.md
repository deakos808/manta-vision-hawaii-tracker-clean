# Historical Kona age-ranking comparison — May 29, 2026

This directory preserves a historical snapshot of Kona manta biopsy age-ranking work produced on May 29, 2026. The files compare the assumptions and resulting relative ranks from Kona Model 1, Model 2, and Model 3.

This snapshot is related to, but not identical to, the newer canonical analysis added in July 2026 under `scripts/analysis/` and `export/analysis/`. It should be treated as historical research provenance, not as the current canonical model output.

The CSV, DOCX, and PDF in this directory are archived outputs copied from the old `New project 2` working folder. The PNG render preview was intentionally omitted because it duplicates the archived PDF.

The corresponding Python report generator is preserved under `scripts/analysis/historical/` for its comparison logic and provenance. Its original machine-specific paths were replaced with explicit input and output path arguments. Dependencies, workbook compatibility, and output reproducibility should be verified before reuse. The small workbook-inspection utility is preserved alongside it for the same historical context.

Do not delete the old source folder until this preservation change has been reviewed, committed, and its copied files and hashes have been verified.
